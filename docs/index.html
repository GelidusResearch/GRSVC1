RECOMMENDED

OTA (Over-The-Air) Update

Update firmware wirelessly using Web Bluetooth. No cables required!

Advantages

  • No cables or drivers needed
  • Works on any modern browser
  • Device stays in enclosure
  • Real-time progress tracking
  • Automatic device restart

Requirements

  • Chrome/Edge browser (Web Bluetooth)
  • Device must be powered on
  • BLE connection required
  • Use .bin firmware file

Quick Steps

  1. Power on your GRSVC1 device
  2. Open the Web UI below
  3. Click "Connect" and select "GRSVC1"
  4. Go to Firmware Update section
  5. Select .bin file and click "Start Update"
  6. Wait for completion and restart

ADVANCED

UF2 Bootloader Update

Direct firmware upload using USB connection and mass storage bootloader.

Advantages

  • Works on any operating system
  • No browser requirements
  • Direct file system access
  • Recovery from firmware issues
  • Fastest upload method

Requirements

  • USB cable (micro USB)
  • Physical access to device
  • Bootloader activation
  • Use .uf2 firmware file

UF2 Upload Steps

  1. Connect GRSVC1 to computer via USB
  2. Double-press RESET button quickly
  3. Device appears as "GRSVC1BOOT" drive
  4. Drag .uf2 file to the drive
  5. Device automatically restarts
  6. New firmware is active

⚠️ Important Safety Notes

  • Never power off the device during a firmware update
  • Use correct firmware files - .bin for OTA, .uf2 for bootloader
  • Ensure stable power - connect USB or ensure battery > 50%
  • Backup settings if you have custom configurations

🔧 UF2 Bootloader Details

What is UF2? UF2 (USB Flashing Format) is a file format developed by Microsoft for flashing microcontrollers over USB mass storage.

Activating Bootloader Mode:

  1. Locate the RESET button on your GRSVC1 device
  2. While connected via USB, double-press RESET quickly (within 0.5 seconds)
  3. The device LED should change pattern to indicate bootloader mode
  4. A new drive called "GRSVC1BOOT" will appear on your computer
  5. If it doesn't work, try pressing RESET while connecting USB

Troubleshooting:

  • If drive doesn't appear, try different USB cables/ports
  • Ensure you're double-pressing RESET quickly enough
  • Some computers may take a few seconds to recognize the drive
  • Try pressing RESET while plugging in USB cable

📱 Browser Compatibility

OTA Updates require Web Bluetooth support:

  • ✅ Chrome (recommended) - Desktop and Android
  • ✅ Microsoft Edge - Desktop
  • ✅ Opera - Desktop and Android
  • ❌ Firefox - Web Bluetooth not supported
  • ❌ Safari - Web Bluetooth not supported
  • ❌ iOS browsers - Web Bluetooth not available

For unsupported browsers, use the UF2 bootloader method instead.

🆘 Recovery Options

If your GRSVC1 device becomes unresponsive after a firmware update:

  1. Try UF2 Recovery: Use the bootloader method to flash known-good firmware
  2. Hard Reset: Hold RESET button for 10+ seconds while powered
  3. Power Cycle: Disconnect power/USB for 30 seconds, then reconnect
  4. Factory Reset: Use the original factory firmware if available
